Compatibility

The games we have tested and the settings that work best for them. The list grows as more games are tested.

Settings for each game

Most games run best with the default settings (the preset CarloDS chooses for your device). The table lists the games for which a specific setting helps. To give a game its own settings, open the Game menu while playing and turn on “Separate settings for this game”.
